# 哲浩之谕 · Tetsuhiro-Lang

**以文言书写 · 以栈运化 · 铸为静态 ELF**

一门以古汉语书写的栈式编程语言。编译器 `zhc`（哲浩之谕）以 Go 撰成，
将 `.浩` 界经译为 AMD64 汇编，经系统 `as`、`ld` 铸为**无 libc 之静态 Linux 可执行文件**。

## ✨ 特性

| | |
|---|---|
| 🖌 **纯文言语法** | 无空格、无外邦符号：名号书于 `《》`，文辞书于 `「」`，数书汉数（`三十四`、`三点一四`），注以 `注曰「……」` |
| 🧱 **栈式核心** | 诸敕皆与栈相往来，`复 弃 换 凌 转` 五字运栈，术（函数）循「栈之礼」——受参自栈取，成果留栈顶 |
| ⚙️ **真编译** | 直接生成 x86-64 汇编（Intel 句法），经系统 `as`/`ld` 铸为静态 ELF；宣聆以 syscall 直通核，无 libc 之倚 |
| 🏷 **带标记值** | 64 位 tagged value：数、虚、阴阳、文、列、典、浮，低三位记其类 |
| 🧩 **经籍模块** | `承` 字纳**经卷**（`.浩`）与**典册**（`.哲`），经经相承，讳相循环 |
| 🛡 **宥劫机制** | `宥……毕宥` 捕获运行之劫，宽宥其故，界乃得全 |
| 🎲 **天机** | `百天机` 得〇至九十九间之天机数 |

## 🚀 快速开始

哲浩之谕第一界——`例/首例.浩`：

```text
哲浩御世。
注曰「首例——万物之首要示现：问候本源」

「浩哉，哲浩御世之界！」宣。
二、三加五乘宣。  注曰「得二十五」
九根宣。          注曰「得三」
「浩」三乘宣。    注曰「得「浩浩浩」」
归源。
```

铸之且行：

```bash
make build                      # 注曰「炼石为器：铸 zhc/zhc」
zhc/zhc 例/首例.浩 -o 首例 --run  # 注曰「铸后即行」
# 注曰「或一步验之：」
make check
```

```console
$ ./首例
浩哉，哲浩御世之界！
25
3.0
浩浩浩
```

## 📦 安装

从 [Releases](https://github.com/ZhehaoTetsuhiro/Tetsuhiro-Lang/releases/latest) 下载：

| 平台 | 文件 |
|------|------|
| Linux x86-64 | `zhc-vX.Y.Z-linux-amd64`（静态链接，仅需系统 `as` 与 `ld` 铸界） |

或从源码构建（需要 Go ≥ 1.25 与 binutils）：

```bash
git clone https://github.com/ZhehaoTetsuhiro/Tetsuhiro-Lang.git
cd Tetsuhiro-Lang
make install  # 注曰「安器于 ~/.zhc/zhc，且录 ~/.zhc 于 ~/.bashrc 之 PATH」
```

## 🧭 编译器用法

```text
zhc <界.浩> [-o 出] [-s 出.s] [--run]
```

| 旗 | 义 |
|---|---|
| `-o 出` | 可执之名（默认取界名去后缀） |
| `-s 出.s` | 汇编之名（默认 `<出>.s`） |
| `--run` | 铸后即行 |

- 界以「哲浩御世」开篇，以「归源」收官。
- 界中可取化生「**外众**」（一列），得命令行所附之众。
- 误犯则本源垂示于误途：「哲浩垂示：……」，其行归一。

## 🏗 编译器器制

<details>
<summary><b>器制大略（<code>zhc/</code>，Go 撰成）</b></summary>

- **四部**：`lexer.go`（切字）→ `parser.go`（立敕）→ `codegen.go`（出汇编）→ `runtime.go`（界之常制）。
- **值之制**：64 位带标记之数——低三位记其类（〇数、一虚、二阴、三阳、四文、五列、六典、七浮），
  数左移三位而栖；文、列、典、浮则藏其指针于堆。
- **寄存器之约**：`r15` 值栈、`r14` 堆、`r13` 循环栈、`r12` 宥栈；机栈与帧循俗礼（rbp/rsp）。
- **宣聆**：以 syscall（write/read）直通核，无 libc 之倚；输出经四千字之缓冲，临寂则刷，聆前亦刷。
- **堆**：`mmap` 匿名十六兆，增而不减；栈余各域亦 `mmap` 而得。
- **模块**：`承《名》` 先寻 `《名》.哲`（典册），次寻 `《名》.浩`（经卷），同目录，讳相循环。

</details>

<details>
<summary><b>今所限于编译器者</b></summary>

浮点巨数（逾二之六十三方者）之印未精；典之历序无定（哈希之序）；`读简` 以简牍之长为准，非寻常之流。

</details>

## 🔧 Makefile 敕令

| 敕 | 义 |
|---|---|
| `make build` | 铸编译器 `zhc` 于根下 |
| `make install` | 安器于 `~/.zhc/zhc`，且录 `~/.zhc` 于 `~/.bashrc` 之 PATH |
| `make uninstall` | 毁器并涤寻径之录 |
| `make check` | 取 `例/首例.浩` 试铸且运行，以验其器 |
| `make clean` | 去根下所铸之 `zhc` |
